# OneBlink Web

Sitio web oficial de **OneBlink** — el marketplace de Cuba.

## Contenido
- `index.html` — Política de Privacidad (página pública principal por ahora)

## Cómo publicar en GitHub Pages
1. GitHub → repo `ledexsoft/OneBlinkWeb` → **Settings** → **Pages**
2. En *Build and deployment* → *Source*: **Deploy from a branch**
3. Branch: `main` → carpeta `/ (root)`
4. Save → esperá 1-2 min → la web queda en:
   `https://ledexsoft.github.io/OneBlinkWeb/`

## Futuro

(catálogo, propiedades, blog, etc.). La política de privacidad quedará en
`/privacidad` o como página separada cuando haya router.
